# СЗИ-Аудит

ПО «СЗИ-Аудит» — аудит средств защиты информации автоматизированных рабочих мест (АРМ).
Графический интерфейс (WPF), управление эталоном, проверки локальных и удалённых АРМ,
история, сравнение результатов и формирование отчётов.

## Состав

| Файл | Назначение |
|---|---|
| `SziAudit.ps1` | Главный модуль: GUI, эталон, запуск проверок, история, отчёты |
| `SziAudit.Checks.ps1` | Модуль проверок |
| `Config/Etalon.xml` | Эталонная конфигурация профилей АРМ |
| `Run-SziAudit.bat` | Запуск графического интерфейса |
| `Run-SziAudit-Daily.bat` | Консольный запуск для Планировщика заданий |
| `arm.txt` | Перечень АРМ для ежедневного аудита |

## Требования

Windows PowerShell 5.1, .NET Framework 4.5 и выше, запуск от имени администратора.

## Запуск

- GUI: `Run-SziAudit.bat`
- Консоль: `powershell.exe -ExecutionPolicy Bypass -File SziAudit.ps1 -NoGui -ProfileId ARM_OPK -ComputersFile arm.txt`

Коды завершения консольного режима: 0 – несоответствий нет; 1 – выявлены несоответствия;
2 – ошибки выполнения проверок; 3 – ошибка запуска.
